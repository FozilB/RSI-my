# RSI кандидат — сканер OKX с сообщениями в Telegram

Бот каждые 2 часа проверяет самые ликвидные USDT-перпетуалы OKX на **4-часовых свечах** и присылает сообщение 🟡 «RSI кандидат», когда выполнено условие:

1. RSI(14) на закрытии свечи вышел выше **75** (монета «взведена»);
2. потом RSI на закрытии свечи опустился до **71.5** или ниже — это кандидат.

Это то же условие, что в индикаторе TradingView «RSI Candidate». RSI считается так же, как `ta.rsi` в TradingView (по Уайлдеру).

Бот каждый раз заново прогоняет условие по последним 300 закрытым свечам каждой монеты, поэтому пропущенный запуск ничего не ломает. Одна и та же свеча не отправляется дважды.

## Что в сообщении

```
🟡 RSI кандидат · SOL/USDT

Таймфрейм: 4ч, свеча закрылась 01.11 21:00 (Ташкент)
Цена сейчас: 205.4 (21:03)
RSI(14): 70.8 — вернулся к 71.5 после выхода выше 75
Максимум RSI: 79.2 (на прошлой свече, 01.11 17:00)
Объём свечи: ×1.6 от среднего

График TradingView
```

Цифры в примере условные. Все времена по Ташкенту. Уровней входа бот не предлагает.

## Расписание

Запуск каждые 2 часа в :02 по UTC, то есть в 05:02, 07:02, 09:02 … по Ташкенту. Свечи 4ч закрываются в 05:00, 09:00, 13:00, 17:00, 21:00 и 01:00 по Ташкенту, их бот и проверяет. В остальные запуски новой свечи ещё нет, и бот завершается за несколько секунд.

Между запросами к бирже бот делает паузу 8 секунд (`REQUEST_PAUSE`), чтобы биржа не блокировала адрес GitHub. Проход по 75 монетам занимает около 10 минут, поэтому по последним монетам сообщение может прийти минут на 10 позже закрытия свечи. GitHub иногда запускает расписание с задержкой в несколько минут.

## Установка (один раз)

1. На GitHub создайте новый репозиторий. Лучше **Public**: в публичных репозиториях Actions бесплатны без ограничения по минутам. В коде нет паролей, секреты хранятся отдельно.
2. Загрузите все файлы из архива в репозиторий: Add file → Upload files. Папку `.github` тоже нужно перетащить, а файл `.gitignore` не пропустить.
3. Settings → Secrets and variables → Actions → New repository secret. Добавьте два секрета:
   - `TELEGRAM_BOT_TOKEN` — токен бота из @BotFather;
   - `TELEGRAM_CHAT_ID` — номер вашего чата.
4. Вкладка Actions → слева «Scan» → Run workflow → отметьте `test_telegram` → Run. В Telegram должно прийти тестовое сообщение.
5. Дальше бот запускается сам каждые 2 часа.

Если в Actions кнопка Run workflow не появилась, нажмите на вкладке Actions «I understand my workflows, go ahead and enable them».

## Настройки

Все числа в файле `config.py`: уровни RSI (`RSI_UPPER`, `RSI_BACK`), период RSI, количество монет, таймфреймы. Изменить файл можно прямо на GitHub (значок карандаша) и сохранить кнопкой Commit.

## Как проверить, что бот работает

Actions → любой запуск → Scan → шаг «Запуск сканера». В конце лога строка «Итог»: сколько монет проверено, сколько ошибок запросов к бирже, сколько кандидатов найдено и отправлено. Если ошибок много, увеличьте `REQUEST_PAUSE` в `config.py`.

Пробный запуск без отправки в Telegram: Run workflow → `dry_run`. Текст сообщений появится в логе. Если на последней свече кандидатов нет, в логе их не будет, это нормально.

## Важно

- В публичном репозитории без изменений GitHub выключает расписание через 60 дней. Тогда на вкладке Actions нужно нажать Enable.
- Это инструмент поиска ситуаций, а не гарантия результата.
